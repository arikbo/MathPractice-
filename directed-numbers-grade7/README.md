# תרגול מספרים מכוונים לכיתה ז׳

האתר נמצא ב-[index.html](index.html), בתיקייה נפרדת כדי לא לפגוע באתר הקיים.

## חיבור גיליון ציונים

1. צרו גיליון Google Sheets פרטי.
2. Extensions → Apps Script → הדביקו את קוד הקובץ Code.gs.
3. Deploy → New deployment → Web app. בחרו Execute as: Me; Who has access: Anyone; אשרו הרשאות.
4. העתיקו את כתובת /exec.
5. החליפו ב-index.html את REPLACE_WITH_APPS_SCRIPT_EXEC_URL בקישור /exec.
6. בדקו הגשה בגיליון. אל תשתפו את הגיליון עם התלמידים.

## פרסום האתר

אפשר להפעיל GitHub Pages (Settings → Pages → Deploy from branch → main → root).
בכתובת האתר פתחו את הנתיב /directed-numbers-grade7/.

## מגבלות חשובות

- אין הרשמה; הזהות והציונים אינם מאומתים וניתנים לזיוף. מתאים לתרגול, לא למבחן רשמי.
- תלמיד יכול לנסות שוב עד שמצליח, ולכן לאחר שכל 12 השאלות נפתרו הציון הוא 12/12. זה מדד השלמה, לא דיוק בניסיון הראשון.
- Google Apps Script מקבל POST ציבורי. מומלץ לבדוק ולאמת את ההגשות ידנית.
- no-cors אינו מאפשר לדפדפן לוודא שהתוצאה נקלטה באמת בגיליון.
- המורה צריך לבדוק מהי מדיניות המוסד לגבי איסוף שמות תלמידים.
